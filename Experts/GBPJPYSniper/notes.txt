how to produce signal for entry and exit?
there is 8 entry signal and 61 exit signal
each entry signal encapsulated in expert signal class
master signal object will contains all 8 entry signal object
if one of the signal is weighted more than 0 then entry position

create SignalMain
initialize SignalMain with all of Signal needed
Implement LongCondition to calculate all sub signal long condition weight
Implement ShortCondition to calculate all sub signal short condition weight
Implement CheckCloseLong check long position exists and check close long condition
Implement CheckCloseShort check short position exists and check close short conditon 
Implement CheckReverseLong for reverse long signal 
Implement CheckReverseShort for reverse short signal
